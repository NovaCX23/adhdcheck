# Star Path: third-party assets

Star Path plays the Kenney sound samples that Bridge Wait self-hosts under `apps/web/public/games/bridge-wait/audio/` (`assetBase` in `mount.ts` defaults to `/games/bridge-wait`). It ships no asset of its own.

Provenance, files, source pages and licence: see [../bridge-wait/ASSETS.md](../bridge-wait/ASSETS.md). Kenney, CC0 1.0, as stated there ("License: (Creative Commons Zero, CC0) http://creativecommons.org/publicdomain/zero/1.0/ ... free to use in personal, educational and commercial projects").
